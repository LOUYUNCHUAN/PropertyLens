# HDB ResaleXAI Backend (`backend/`)

FastAPI backend for the HDB ResaleXAI project. It loads pre-trained models and artefacts from `../data/processed/` and exposes prediction, explanation, CBR, analytics, counterfactual, and chat endpoints.

---

## 1. Prerequisites

- Python 3.11 (recommended)
- Virtual environment created at project root: `.venv/`
- Data & artefacts already generated by the notebooks:
  - `data/processed/hdb_features.parquet`
  - `data/processed/xgb_model.joblib`, `bayesian_model.joblib`, `lr_model.joblib`
  - `data/processed/shap_explainer.joblib`, `lime_training_data.joblib`
  - `data/processed/cbr_index.joblib`, `cbr_scaler.joblib`, `cbr_training_data.parquet`, `cbr_features.json`
  - `data/processed/feature_columns.json`, `global_shap_cache.json`, `rules.json`

> NOTE: `rf_model.joblib` (1.1GB) exists but is **not** loaded at startup.

---

## 2. Activate the virtual environment

From the project root (`HDB project/`):

```bash
python -m venv .venv          # only if you haven't created it yet
source .venv/bin/activate     # macOS / Linux
# .venv\Scripts\activate      # Windows PowerShell (if applicable)
```

You should now see `(.venv)` in your shell prompt.

---

## 3. Install backend dependencies

With the venv **activated** and from the project root:

```bash
pip install -r backend/requirements.txt
```

This installs FastAPI, Uvicorn, scikit-learn, XGBoost, SHAP, LIME, etc. into your `.venv`.

---

## 4. Run the FastAPI backend

From the project root (venv active):

```bash
cd backend
uvicorn main:app --reload --port 8000
```

- `--reload` auto-restarts on code changes (dev mode).
- The API will be available at `http://127.0.0.1:8000`.

If artefact loading is successful, you will see logs similar to:

```text
Loading artefacts...
✅ All artefacts loaded
   Features: 49
   CBR cases: 7xx,xxx
INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
```

---

## 5. Health check (/health)

Verify the backend is running and models are loaded by calling the health endpoint.

### Using curl

```bash
curl http://127.0.0.1:8000/health
```

You should get a JSON response like:

```json
{
  "status": "ok",
  "model": "Hybrid Cluster Ensemble",
  "rmse": 37791,
  "r2": 0.9658,
  "mape_pct": 4.01,
  "features": 77
}
```

### Using a browser

Open:

- `http://127.0.0.1:8000/health` — health JSON
- `http://127.0.0.1:8000/docs` — Swagger UI (interactive API docs)

---

## 6. Common issues

- **`ModuleNotFoundError: No module named 'lime'`**
  - Ensure you installed backend requirements inside the venv:
    ```bash
    source .venv/bin/activate
    pip install -r backend/requirements.txt
    ```

- **`XGBoostError: Library not loaded: libomp.dylib` on macOS**
  - Install the OpenMP runtime once:
    ```bash
    brew install libomp
    ```
  - Then restart the venv and Uvicorn server.

If problems persist, confirm you’re running `uvicorn` from the same venv used to run the notebooks (`which python` should point into `.venv/`).
